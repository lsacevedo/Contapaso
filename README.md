# ContaPaso 📊

**Guía didáctica de resolución de ejercicios de Kardex e Inventarios para estudiantes de contabilidad.**

ContaPaso es una aplicación web interactiva que ayuda a estudiantes de primeros semestres a comprender paso a paso los métodos de valuación de inventarios (**PEPS / FIFO**, **UEPS / LIFO** y **Promedio Ponderado**), tanto en el sistema **Permanente** como en el **Periódico**.

---

## 🎯 Características Principales
1. **Configuración de Taller:** Selección táctil entre Kardex Permanente e Inventario Periódico y métodos de valuación.
2. **8 Preguntas Frecuentes Didácticas:** Explicación sencilla de conceptos clave de inventarios y NIIF / NIC 2.
3. **Ingreso y Validación de Operaciones:** Registro de inventario inicial, compras y ventas con alertas de sobreventa en tiempo real.
4. **Kardex Paso a Paso:** Desglose lote a lote mostrando de qué compra sale cada unidad.
5. **Análisis Comparativo:** Comparativa simultánea de resultados e impacto financiero.

---

## 🚀 Cómo ejecutar en local
Basta con abrir el archivo `index.html` en cualquier navegador web moderno (Google Chrome, Microsoft Edge, Firefox, Safari). No requiere instalaciones complejas ni bases de datos locales para el funcionamiento básico.
